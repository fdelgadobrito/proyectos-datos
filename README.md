# Proyectos de Análisis y Ciencia de Datos

Código de los proyectos presentados en mi [portafolio](https://fdelgadobrito.github.io/).

Los primeros cuatro parten del mismo dataset (53.727 ventas de autos usados en
Chile, 2020–2025); el quinto es un proyecto de optimización de inventario para
otra empresa.

## Proyectos

1. [Limpieza de datos](01-limpieza-datos-autos/) — Python, Pandas. Poner en
   orden el dataset original: duplicados, nulos y errores de formato.
2. [Predicción de precio](02-prediccion-precio-random-forest/) — Scikit-learn,
   GridSearchCV. Ocho algoritmos de regresión comparados; Random Forest gana
   con R² de 0.96.
3. [Análisis descriptivo](03-analisis-descriptivo-precio/) — Estadística
   descriptiva y correlación. Qué explica realmente el precio de un auto.
4. [Optimización de inventario semanal](04-optimizacion-inventario-semanal/) —
   PuLP, programación lineal. Cuántos sedanes y pickups preparar cada semana.
5. [Inventario con cadenas de Markov](05-inventario-cadenas-markov-r/) — R,
   simulación. Caso real de gestión de inventario (datos del cliente
   anonimizados).
